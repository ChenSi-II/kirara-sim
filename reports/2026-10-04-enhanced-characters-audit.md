# 强化角色描述与实现核对

> 后续实现和验证见 [14 名强化旧角色实现记录](2026-10-04-enhanced-characters-implementation.md)。本文保留实施前的审计结论。

核对日期：2026-10-04。Git 基准：`c3395ff74c0def84ac0e0d05a5f0cefd373ce7e5`（当前 HEAD）。比较对象是工作区 `origin_data`，代码也按当前工作区读取。

**结论：梦见月瑞希有实质性修改。两批共 14 位旧角色中，13 位确认有强化实现缺口或错误；菲谢尔的本次强化条目静态核对未发现不一致。** 另检查了 5 位带同类标记的新角色，洛恩、布伦妮缺魔导机制，法尔伽漏接星扩散；杜林、尼可的天赋4分支已接入。

本次是审计，新增本报告及配套差异 JSON，没有修改角色实现。下述“未发现不一致”仅针对本次强化条目，不是角色全部机制、动作帧或伤害结果的完整认证。没有运行战斗回归测试。

## 比较方法与范围

- 使用 `git show HEAD:origin_data/Avatars/<ID>.json` 获取旧版本，递归对比 JSON；键名大小写、字段顺序、缩进、整数/浮点表示差异不计入机制变化。
- 参数数组末尾补零、技能描述数组末尾补空字符串不计入机制变化。背景、故事和养成材料不在本次战斗审计范围内。
- 配套文件 [enhanced-characters-diff.json](2026-10-04-enhanced-characters-diff.json) 保留技能、天赋、命座等字段的实际差异及原文，数组下标从 0 开始。`Unlock` 变化作为元数据保留，不认定为战斗数值变化。
- `Attack`、`Energy` 未纳入配套文件的技能描述差异统计；部分旧角色新增这两类元数据，部分列表重排，不能直接按文本 diff 行数判定机制修改。瑞希这两类数据在本次比较中没有实质变化。
- 综合顶层 `Special`、条目级 `Special`、非空 `SpecialDesc` 和第四个 `Passives` 条目筛选；强化描述为空时读取该条目的 `Desc`。**数据中的“天赋4”是第四个被动条目，不等于 Go 文件中表示突破四阶天赋的 `a4()`。**
- 按描述可将用户提及的两批旧角色对应为：第一批 7 位魔导强化角色；第二批 7 位辉映强化角色（风/冰/雷）。这是依据数据内容的分组，不是对发布批次历史的独立考证。
- 同类标记另外命中 5 位新魔导角色，作为补充范围检查。旅行者各元素的“异邦的…”条目属于独立的元素共鸣强化体系，男女旅行者还有重复数据，不计入这两批 14 人；本报告不对旅行者实现作出结论。

## 梦见月瑞希：Git 实质变化

源文件：[10000109.json](../origin_data/Avatars/10000109.json)。去除键名及参数补零等噪声后，有 7 个技能/天赋/命座叶字段变化，其中包括以下机制调整：

| 位置 | HEAD → 工作区 | 判定 |
| --- | --- | --- |
| 一命 `SpecialDesc`、`ParamList[4]` | 辉映追加伤害从 **600% 精通 → 400% 精通**，参数 `6 → 4` | 明确数值修改 |
| 天赋4 `Desc` | 强化下次周期伤害的触发条件从“扩散”扩展为“扩散或星扩散” | 明确触发条件修改 |
| 天赋4 `Desc` | 明确队伍角色在附近触发星扩散后进入辉映，持续 8 秒；重述强化伤害的追加星扩散伤害 | 前者明确触发主体；后者仍为 1000% 精通，非数值提高 |
| 战技 `Desc` | 精通提供的反应增伤从“扩散”扩展到“扩散与星扩散” | 明确作用范围修改 |
| 六命普通 `Desc` | 补入全队星扩散暴击率 +10%、暴伤 +20% | 普通描述新增；旧 `SpecialDesc` 已经有该效果，不能当作强化版全新效果 |
| 一命普通 `Desc`、六命 `SpecialDesc` | “分别”、标点和语句整理 | 无额外机制变化 |

原始 Git diff 为 1050 行新增、805 行删除，大部分不是机制变化。普攻、战技、爆发各等级原有数值没有改变，技能/天赋参数由 20 项扩至 25 项的新增部分均为零。

## 开关与队伍联动

现有已实现角色使用角色参数 `hexerei` 控制魔导身份，通常默认开启。JSON 的 `Special`/`SpecialDesc` 不是自动运行的技能脚本，更新 JSON 不会自动补出 Go 战斗逻辑。

[player.go](../pkg/core/player/player.go) 的 `GetHexereiCount()` 只统计 `CharWrapper.IsHexerei`。温迪、可莉、阿贝多、洛恩、布伦妮未设置该标记，除了自身强化不工作，还可能让实际双魔导队伍被程序统计成一名，从而影响雷泽、菲谢尔、砂糖、莫娜、杜林、法尔伽、尼可等队友的两名魔导门槛。

后续实现应分别验证：自身强化开关、魔导身份、至少两名魔导的“秘仪”门槛、命座等级，以及辉映的条件与时长。并非所有强化命座或天赋的非“秘仪”部分都要求双魔导，不应一律绑到同一个队伍计数判断上。
